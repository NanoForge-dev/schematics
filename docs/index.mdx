# NanoForge Schematics

`@nanoforge-dev/schematics` provides Angular DevKit schematics for scaffolding NanoForge game engine projects.
It generates project structures, configuration files, client and server base code, Dockerfiles, and main entry
points from project metadata.

The package currently ships these schematics:

- `application`
- `configuration`
- `part-base`
- `part-main`
- `docker`
- `component`
- `system`
